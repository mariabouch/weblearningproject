# 🛒 E-Commerce Frontend Project (HTML • CSS • JavaScript)

## 🎯 Objectif

Ce projet a pour but d’apprendre **le développement web frontend** en construisant un site e-commerce complet uniquement avec :

- HTML (structure)
- CSS (design & responsive)
- JavaScript pur (logique & interactions)

⚠️ Aucun backend pour le moment.  
Nous allons nous concentrer uniquement sur :

- La bonne structure des pages HTML
- Une organisation propre des fichiers
- Le responsive design
- La manipulation du DOM avec JavaScript

---

# 📚 Compétences à développer

## 1️⃣ HTML
- Structure sémantique (`header`, `nav`, `main`, `section`, `footer`)
- Création de formulaires
- Organisation logique d’une page
- Bonnes pratiques

## 2️⃣ CSS
- Sélecteurs
- Flexbox
- Grid
- Responsive design (Media Queries)
- Animations simples
- Organisation du code CSS

## 3️⃣ JavaScript (Vanilla JS)
- Manipulation du DOM
- Gestion des événements
- Création dynamique d’éléments
- LocalStorage
- Validation de formulaires
- Organisation du code JS

---


---

# 🖥️ Pages à développer

## 🏠 1) Page d’accueil (index.html)

Contient :
- Navbar
- Section Hero
- Produits populaires
- Footer

Objectifs :
- Layout avec Flexbox ou Grid
- Responsive design
- Navigation entre pages

---

## 🛍️ 2) Page Produits (products.html)

Contient :
- Liste de produits (générés dynamiquement en JS)
- Bouton "Ajouter au panier"
- Filtre ou tri simple

Objectifs :
- Tableau d’objets produits en JavaScript
- Création dynamique des cards
- Gestion du panier avec LocalStorage

---

## 👤 3) Login Page (login.html)

Contient :
- Email
- Mot de passe
- Validation JS

Objectifs :
- Validation côté client
- Empêcher le submit si erreur
- Simulation d’authentification

---

## 📝 4) Sign Up Page (signup.html)

Contient :
- Nom
- Email
- Mot de passe
- Confirmation mot de passe

Objectifs :
- Vérification des champs
- Regex pour email
- Sauvegarde utilisateur en LocalStorage

---

## 🧑‍💼 5) Panel Page (panel.html)

Contient :
- Informations utilisateur
- Liste des produits du panier

Objectifs :
- Lecture depuis LocalStorage
- Affichage dynamique
- Redirection si non connecté

---

# 🧠 Méthodologie de travail

## 🔹 Étape 1 : HTML uniquement
Créer toutes les pages avec une structure propre.

Aucun CSS.  
Aucun JS.

Valider :
- Structure logique
- Balises sémantiques correctes
- Organisation claire

---

## 🔹 Étape 2 : CSS
Ajouter :
- Layout propre
- Responsive design
- Effets hover
- Design moderne

---

## 🔹 Étape 3 : JavaScript
Ajouter progressivement :
- Manipulation du DOM
- Produits dynamiques
- Gestion panier
- Authentification simulée
